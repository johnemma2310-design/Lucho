### 1. Instalar

```bash
python -m venv .venv
source .venv/bin/activate          
.venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env              
```

```bash
python simular.py
```
Con esto corre Lucho en la consola, se debe de conectar al .Env con los datos requeridos
